# Agent instructions

## Language

Every reply to the user is **one language only**:

- User writes in Hebrew → reply entirely in Hebrew.
- User writes in English → reply entirely in English.
- Never mix Hebrew and English in the same sentence or the same message.
- Do not translate mid-sentence. Do not put English narration inside Hebrew prose, or Hebrew inside English prose.
- File paths, URLs, code, and proper names stay as written. The surrounding sentence stays in the chosen language.

## Reminders

Reminders always go on Google Calendar (`Asia/Jerusalem`), not as conversation-only timers.

- Create timed calendar events (not all-day) with a popup 10 minutes before.
- Google Calendar is the source of truth. Cursor timers are optional backup only.
- Never commit personal calendar files, `.ics` files, or reminder dumps to this website repo.
- If Google Calendar is not connected in this session: say so, then give `calendar.google.com` template links and an `.ics` import file under `/opt/cursor/artifacts`. Do not pretend the events are already on the calendar.
