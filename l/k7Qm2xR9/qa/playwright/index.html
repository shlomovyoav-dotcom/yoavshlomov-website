What a reviewer should look at

  • Page objects hold the locators. Specs read as journeys. A loggedIn fixture signs in as a chosen persona.
  • Checkout totals are computed from the catalog and an 8% tax rate — not copied from a screenshot.
  • A nightly-style script scrapes the live inventory and diffs it against src/data/catalog.ts. Exit 1 on mismatch.
  • API tests hit DummyJSON: list, get-by-id, 404, cart line-item math.
  • problem_user ships with 404 product images in some browsers. The write-up is in the sample bug report. CI checks that the persona can still use the inventory, because the 404 does not reproduce on every runner.

Sample bug report

A real defect on a public demo, written the way I filed billing bugs: account state, steps, expected vs actual, Console/Network evidence, impact.

Title: problem_user — product images 404 on the inventory, so the customer cannot tell items apart
Severity: Major · Env: saucedemo.com · Chrome · 2026-10-17
Account state: problem_user / secret_sauce

Expected: each inventory card shows the product photograph (img.naturalWidth > 0).
Actual: every product image has naturalWidth === 0. DevTools → Network: image requests return 404. Standard user on the same build is fine — persona-specific, not a CDN outage.

Steps: open the demo → Network filter Img, Console open → log in as problem_user → compare with a standard_user session.

Impact: same class as “the number on screen is not the system of record, and it only reproduces on a specific account state.”

Sample SQL

Working, query-level SQL — SELECT, WHERE, GROUP BY, HAVING, COUNT(DISTINCT). Table names are invented.

SELECT
  DATE(e.event_time) AS day,
  COUNT(DISTINCT CASE WHEN e.event_name = 'pricing_viewed' THEN e.user_id END) AS viewed_pricing,
  COUNT(DISTINCT CASE WHEN e.event_name = 'checkout_started' THEN e.user_id END) AS started_checkout
FROM events e
WHERE e.event_time >= CURRENT_DATE - INTERVAL '7' DAY
GROUP BY DATE(e.event_time)
HAVING COUNT(DISTINCT CASE WHEN e.event_name = 'pricing_viewed' THEN e.user_id END) > 0;
